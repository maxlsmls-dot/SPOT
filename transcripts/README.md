# Tegus expert-call transcripts — Spotify (SPOT)

Raw transcripts, one file per call. Pasted from the Tegus web reader (export disabled).

## Naming convention

```
transcripts/NN_YYYY-MM-DD_<expert-role-short>.md
```

- `NN` — sequential call number in the order received (01, 02, ...)
- `YYYY-MM-DD` — call date as shown on Tegus (use `0000-00-00` if unknown)
- `<expert-role-short>` — e.g. `former-spot-marketplace-pm`, `indie-label-exec`, `dsp-consultant`

Each file starts with a header block:

```
CALL: <company or topic> | <date> | <expert's role / former employer>
TEGUS ID: <if visible>
SOURCE: Tegus web reader, pasted <date pasted>
---
<transcript>
```
